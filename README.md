# ⚡ QuickFit

A role-based Flutter fitness app for **students** and **coaches**.

**Students** → track workouts, view progress charts, join challenges  
**Coaches** → assign workouts, manage students, run challenges with live leaderboards

## 🚀 Setup Guide

### 1. Prerequisites
- Flutter SDK ≥ 3.0
- Dart ≥ 3.0
- A Firebase project (free Spark plan works)

### 2. Install Flutter dependencies
```bash
flutter pub get
```

### 3. Create Firebase project
1. Go to https://console.firebase.google.com
2. Create a new project (e.g. `quickfit-app`)
3. Enable **Authentication → Email/Password**
4. Enable **Firestore Database** (start in test mode, then apply the rules)

### 4. Connect Firebase to the app
Install the FlutterFire CLI if you haven't:
```bash
dart pub global activate flutterfire_cli
```
Then run from the project root:
```bash
flutterfire configure
```
This generates `lib/firebase_options.dart` with your real credentials.

### 5. Apply Firestore security rules
Copy the contents of `firestore.rules` into the **Firestore → Rules** tab in your Firebase console.

### 6. Run the app
```bash
flutter run
```

## 🔥 Firestore Data Structure

```
users/{uid}
  uid, email, name, role, profileImageUrl
  studentStats: { workoutsCompleted, challengesJoined, challengesWon, weeklyCompletionRate }
  coachStats:   { totalStudentsTrained, rating, totalWorkoutsCreated }

workouts/{id}
  id, coachId, studentId, title, description
  createdAt, isCompleted, studentNotes, completedAt

challenges/{id}
  id, title, description, startDate, endDate, createdByCoachId
  participants: [{ userId, userName, score, isWinner }]
```
